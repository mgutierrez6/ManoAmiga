## Como ejecutar el programa:
**3 terminales:**
  **1)** cd mano-amiga-server\backend
     npm install (solo la primera vez)
     npm start

  **2)** cd mano-amiga-server\front-service
     npm install (solo la primera vez)
     npm start

  **3)** cd mano-amiga-app
     npm install (solo la primera vez)
     npm start
     *escanear qr y abrir en app Expo Go
