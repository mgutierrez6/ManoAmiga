## Cómo ejecutar el programa

Se necesitan **3 terminales**:

1. **Backend**
```bash
   cd mano-amiga-server\backend
   npm install   # solo la primera vez
   npm start
```

2. **Front service**
```bash
   cd mano-amiga-server\front-service
   npm install   # solo la primera vez
   npm start
```

3. **App**
```bash
   cd mano-amiga-app
   npm install   # solo la primera vez
   npm start
```
   Escanear el QR y abrir en la app **Expo Go**.
